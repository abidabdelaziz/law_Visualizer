# law_Visualizer
This is designed as a complimentary research tool that assists in the visualization of Nations Laws.

As data continues to be compiled and so to will the features of this tool. 

Thank you to NYU Law and University of Ottawas JuriGlobe dB for their well compiled data and the permission to use it.
